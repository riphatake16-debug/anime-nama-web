# انیمه‌نما

[باز کردن سایت](https://riphatake16-debug.github.io/anime-nama-web/)

نسخهٔ اجرایی عمومی انیمه‌نما: آرشیو انیمه‌ها، تقویم پخش به وقت تهران، فهرست شخصی و راهنمای بررسی ادامه‌های ثبت‌شده. فهرست شخصی هر بازدیدکننده فقط در مرورگر خودش ذخیره می‌شود. این مخزن فایل‌های آمادهٔ انتشار سایت را نگه می‌دارد.
