# انیمه‌نما

[باز کردن سایت](https://riphatake16-debug.github.io/anime-nama-web/)

نسخهٔ اجرایی عمومی؛ پخش رایگانِ گزیده از کانال ناشر، آرشیو، فهرست و داشبورد شخصی، خبرهای منبع‌دار، اعلان اختیاری و نصب روی موبایل. ورود امن به حساب برای همگام‌سازی اختیاری است. این مخزن فقط فایل‌های آمادهٔ انتشار را نگه می‌دارد.
