[باز کردن سایت](https://riphatake16-debug.github.io/anime-nama-web/)

## سورس خوانای React (مسیر مهاجرت امن)

پوشهٔ [`source/`](source/README.md) یک پروژه **مستقل React/Vite** داخل **همین مخزن** است که با `npm install && npm run build` ساخته می‌شود. صفحه‌های خانه، آرشیو، تقویم، جزئیات، فهرست شخصی و پشتیبان با کد خوانا پیاده‌سازی شده‌اند؛ آزمون‌های ذخیره‌سازی سازگار با نسخه فعلی و آزمون مرورگر دارند.

**سایت اصلی همچنان از خروجی موجود در ریشه مخزن اجرا می‌شود.** سورس جدید جایگزین بی‌سر و صدای نسخه پایدار نیست؛ ماژول‌های ورود ابری، اخبار، فصل‌های بعدی و اعلان‌ها بازسازی و با دادهٔ شبیه‌سازی‌شده آزموده شده‌اند، اما پیش از مهاجرت کامل باید اتصال واقعی حساب، اعلان‌ها و دستگاه‌های کاربران تأیید شود. هیچ اطلاعات کاربری پاک یا منتقل نشده است و هیچ مخزن دیگری در این کار استفاده نشده.



## هماهنگی تم شب و انیمیشن‌های نسخه v21

- `enhancements/polish-v21.css` برای نسخه فعال: سطوح و فرم‌های تیره یکدست، کنتراست بیشتر در پنجره‌ها، کارت‌های هم‌اندازه و فاصله امن نوار پایین موبایل.
- انیمیشن‌های ورود بخش‌ها و کارت‌ها فقط با `transform` و `opacity`، بدون کتابخانه اضافه؛ تمایل سیستم به کاهش حرکت و تنظیم ذخیره‌شدهٔ `animenama:motion` بر همه حرکت‌ها مقدم‌اند.
- `enhancements/light-v21.js` دکمه جست‌وجوی موبایل و حرکت صفحه را با تنظیم کاهش حرکت سازگار می‌کند؛ `index.html` تم/رنگ مرورگر را پیش از نمایش صفحه آماده می‌کند.
- همین اصلاحات در `source/src/polish.css` و سورس React اعمال شدند و فایل‌های PWA نسخه فعال روی `animenama-v21` تنظیم شدند.
- تست Chromium نسخه فعال، تست سورس مستقل و QA مبتنی بر WebKit در GitHub Actions وجود دارد. WebKit لینوکس جای تأیید Safari واقعی آیفون را نمی‌گیرد.
- **مهاجرت سورس React به صفحه اصلی هنوز انجام نشده** و به بررسی امن حساب و اعلان‌های واقعی نیاز دارد. هیچ دادهٔ شخصی هنگام تغییر پوسته پاک نمی‌شود.

## آماده‌سازی نسخه ۱.۰ (Release Candidate)

قبل از انتشار رسمی، **[چک‌لیست انتشار و آزمون‌های باقیمانده](RELEASE_V1.md)** را ببینید.

- آزمون‌های خودکار فایل‌های انتشار، اعتبار تقویم، رفتار در قطع سرویس‌های اطلاعاتی و کش آفلاین: `node scripts/audit.mjs` و `node --test tests/*.test.mjs`.
- آزمون واقعی Chromium موبایل و دسکتاپ با Playwright در GitHub Actions: `.github/workflows/browser-qa.yml`. این آزمون فهرست آزمایشی، خروجی/بازیابی پشتیبان، تم، تقویم و وضعیت آفلاین را کنترل می‌کند؛ به حساب واقعی دست نمی‌زند.
- Service Worker نسخه v20؛ در حالت آفلاین از باندل اجرایی فعلی و فایل عمومی انیمه‌ها استفاده می‌کند. اگر همهٔ منابع API قطع باشند، زمان آخرین داده موفق به‌روزرسانی ساختگی نمی‌شود.
- **هنوز برچسب نهایی v1.0.0 زده نشده**؛ تأیید Safari/Android واقعی، عملکرد و همگام‌سازی ابری حساب آزمایشی در چک‌لیست باز است.


نسخهٔ اجرایی عمومی؛ آرشیو، فهرست و داشبورد شخصی، خبرهای منبع‌دار، اعلان اختیاری و نصب روی موبایل. ورود امن به حساب برای همگام‌سازی اختیاری است. این مخزن فقط فایل‌های آمادهٔ انتشار را نگه می‌دارد.

## ارتقای سینمایی (Cinematic Experience)

این ارتقا بدون تغییر داده‌های فهرست شخصی یا منطق اصلی برنامه، به فایل‌های آمادهٔ انتشار اضافه شده است:

- **تم سینمایی تاریک** با امکان برگشت به تم روشن از دکمهٔ خورشید/ماه در بالای سایت.
- **منوی دسترسی سریع** با دکمهٔ جست‌وجو یا کلیدهای `Ctrl+K`، `⌘K` یا `/` (خارج از فیلدهای ورودی).
- پیمایش سریع بین خانه، آرشیو، تقویم و فهرست، جست‌وجوی مستقیم انیمه، انتخاب شانسی و باز کردن تنظیمات و خبرها.
- دسترس‌پذیری بهتر: لینک «رفتن به محتوای اصلی»، وضعیت انتخاب با کیبورد، پشتیبانی از کاهش حرکت.
- نمایش بهتر کارت‌ها و کنتراست صفحه در موبایل و دسکتاپ؛ نوار پیشرفت اسکرول و بازگشت به بالای صفحه.
- تنظیم تم صرفاً در مرورگر ذخیره می‌شود و اطلاعات حساب کاربری را لمس نمی‌کند.

فایل‌های مستقل این بخش در `enhancements/` هستند. برای برگشت کامل، ارجاع‌های این دو فایل در `index.html` را حذف کنید و نسخهٔ Service Worker را افزایش دهید. بخش اصلی React و API بدون تغییر مانده‌اند.


## بهینه‌سازی فنی v14 (۳۱ اکتبر ۲۰۲۶)

- بارگیری پوسترهای محلی با `IntersectionObserver` تنها وقتی کارت به محدودهٔ قابل مشاهده نزدیک می‌شود (حاشیهٔ ۲۵۰ پیکسل). این اصلاح برای همهٔ کارت‌ها در باندل نسخه‌دار `assets/index-optimized-v14.js` اعمال شده است. در مرورگرهای بدون این API، بارگیری قدیمی انجام می‌شود.
- تصاویر با `loading=lazy` بارگیری می‌شوند؛ درخواست‌های شکست‌خوردهٔ بسته‌های پوستر می‌توانند دوباره تلاش شوند.
- لایهٔ اضافی v13 (۲۸٫۵ کیلوبایت خام) با یک لایهٔ سبک v14 (۱۲٫۶ کیلوبایت خام) جایگزین شده است؛ جست‌وجو از جست‌وجوی اصلی خود برنامه استفاده می‌کند.
- تم روشن پیش‌فرض است و حالت تاریک همچنان انتخابی است. تغییر پوستر و فهرست شخصی نیازمند حذف یا مهاجرت داده نیست.
- کش پوسترهای JSON از کش فایل‌های اصلی جدا شده و حداکثر ۹ بسته نگه می‌دارد؛ خطاهای سهمیهٔ ذخیره‌سازی پاسخ آنلاین را خراب نمی‌کنند. نصب SW فقط بعد از دریافت کامل فایل‌های حیاتی فعال می‌شود.
- فایل‌های JS و CSS جدید مسیر نسخه‌دار مستقل دارند تا کش نسخهٔ پیشین با نسخهٔ جدید اشتباه نشود.

**محدودیت ارزیابی:** این مخزن صرفاً فایل‌های build شده است و کد منبع React، ابزار build، و آزمون Lighthouse/Playwright در آن وجود ندارد. اعداد مربوط به اندازهٔ خام فایل‌های مخزن‌اند، نه امتیاز PageSpeed. تغییر زمان LCP/INP به آزمایش مرورگر و شبکه نیاز دارد. اطلاعات شخصی، ورود و APIها در این به‌روزرسانی تغییر نکرده‌اند.

## اصلاح نمایش پوسترها — v15

- پوسترهایی که آدرس مستقیم آن‌ها از API دریافت شده، بلافاصله و با بارگیری تنبل نمایش داده می‌شوند؛ دیگر منتظر دریافت JSON پوستر محلی نمی‌مانند.
- در صورت خرابی تصویر اصلی، کد مسیرهای جایگزین همان انیمه و سپس پوستر محلی (در صورت وجود) و AniList را امتحان می‌کند.
- **۲۱۰** تعداد پوسترهای پشتیبان محلی است، **نه** محدودیت تعداد انیمه‌ها. آرشیو اصلی از API با صفحه‌بندی، جست‌وجو و فیلتر «هنوز پخش نشده» اطلاعات روز را می‌گیرد؛ موردی که هنوز در منبع ثبت نشده قابل نمایش نیست.
- فایل JS و کش آفلاین به v15 ارتقا یافتند تا مرورگر نسخهٔ قدیمی را نگه ندارد. اطلاعات «فهرست من» تغییر نکرده‌اند.
- تغییرات v15 فقط در خروجی build انجام شده‌اند؛ بهتر است در اولین دسترسی به source React نیز اعمال شوند.

## طراحی Midnight Cinema v16 — الهام‌گرفته از طرح Dribbble

مرجع بصری: https://dribbble.com/shots/19415785-Anime-Streaming-App . طراحی و کد مستقل‌اند و تصویر یا عناصر اختصاصی طرح مرجع در مخزن کپی نشده‌اند.

- تم سرمه‌ای بسیار تیره با رنگ تأکیدی آبی؛ کاربران دارای انتخاب صریح «روشن» همان ترجیح را حفظ می‌کنند.
- بنر شاخص پویا از اولین انیمهٔ دریافت‌شدهٔ بخش «در حال پخش» و دکمهٔ کارکردی جزئیات (استفاده از رویداد اصلی React).
- پوسترهای برجسته، اسکرول افقی بخش پیشنهادها روی موبایل، ناوبری شناور و کارت‌های خواناتر برای آرشیو، تقویم، جست‌وجو، فهرست شخصی و پنجرهٔ جزئیات.
- هیچ دکمهٔ پخش/دانلود غیرواقعی به برنامه اضافه نشده؛ انیمه‌نما همچنان سرویس کشف و پیگیری انیمه است.
- همهٔ منطق حساب، فهرست شخصی، API و بارگیری پوسترهای v15 بدون تغییر است. تغییرات به‌صورت افزونهٔ قابل حذف در `enhancements/streaming-v16.{css,js}` هستند.
- برای برگشت از این طراحی: ارجاع فایل‌های v16 را از `index.html` بردارید، به فایل قبلی تم برگردید و نسخهٔ Service Worker را افزایش دهید.

محدودیت: این مخزن فقط خروجی build شده را دارد؛ تغییرات ساختاری React نیازمند سورس اصلی و آزمون مرورگرهای واقعی است.

تکمیل طراحی (v17 cache): سایهٔ بنر برای نوشتار راست‌به‌چپ تصحیح شد و URLهای تصویری خراب در بنر تا بارگذاری مجدد صفحه دوباره امتحان نمی‌شوند؛ نسخه کش تغییر کرد.

## حذف کامل بنر آبی صفحه خانه — v18

بنا به درخواست، بنر بزرگ آبی «منتخب این فصل» به‌طور کامل از صفحه خانه حذف شد؛ افزونهٔ JavaScript سازندهٔ آن و CSS مخصوصش دیگر در سایت یا پیش‌کش حضور ندارند. طراحی سرمه‌ای سایر بخش‌ها و قابلیت‌های آرشیو، تقویم، فهرست شخصی و ذخیره‌سازی بدون تغییر باقی مانده است. فایل استایل فعال `enhancements/streaming-v18.css` و نسخه Service Worker اکنون v18 است.

## رفع نمایش خالی خانه — v19

- برای GitHub Pages، صفحهٔ خانه و تقویم ابتدا فایل عمومی `data/home.json` را از دامنه خود سایت می‌خوانند؛ در صورت نبودن داده، درخواست مستقیم به سرویس‌های Tenrai و Jikan برقرار می‌ماند.
- workflow `.github/workflows/refresh-home.yml` با زمان‌بندی ۶ ساعته داده عمومی «در حال پخش» و برنامهٔ روزهای هفته را در مخزن به‌روز می‌کند. نسخه اولیهٔ خالی به‌جای اطلاعات ساختگی قرار گرفته و با اولین اجرای موفق workflow جایگزین می‌شود.
- مسیر `/api/anime` که در GitHub Pages موجود نیست، دیگر در این هاست امتحان نمی‌شود؛ زمان انتظار هر سرویس جایگزین کوتاه‌تر شده و سرویس‌ورکر فایل عمومی را به‌صورت network-first نگه می‌دارد.
- داده‌های کاربر، ورود و فهرست شخصی دست‌نخورده‌اند. عدم دسترسی تلفن به CDN تصویر همچنان می‌تواند باعث خالی‌شدن پوسترهای همان منبع شود.
